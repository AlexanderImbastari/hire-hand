# 2026-09-11 — Web UI from the design handoff

Built the seven screens in `design_handoff_hirehand_web` against the existing data
layer. Branch: `design/web-ui`.

The handoff's `DESIGN-SYSTEM.md`, `domain.md` and `offer_catalog.md` were byte-identical
to the copies already in `prompts/context/`, so nothing there needed reconciling.

## What changed

**Design system.** `app/globals.css` was rewritten: the old teal/clay palette is gone,
replaced by the handoff's tokens (one orange accent, ink greys, four radii, two
shadows). Manrope and JetBrains Mono load through `next/font`.

**Routing.** The product was a single client-rendered page switching on role. It is now
real routes — `/`, `/jobs`, `/jobs/[id]`, `/jobs/new`, `/dashboard`, `/quotes`,
`/pricing`, `/login`, `/styleguide` — with `SessionProvider` lifted into the root
layout. `components/App.tsx` became the route guards it needed to be.

**`shared/` is untouched except for two additive changes** (below). Every screen reads
through `shared/data.ts`; no component touches storage or policy directly.

## Decisions worth recording

**Tokens live in `@theme`, not `tailwind.config.ts`.** The handoff says to put them in
the config; this project is on Tailwind 4, which is CSS-first and has no config file.
The instruction's intent — define tokens centrally, never scatter hex — is met.

**`quoteCount` added to `JobPublicView`.** The browse cards show "3 quotes" and the
detail page shows "Quotes so far". Nothing exposed a count. A count is competitive
signal, not a rival's price, so it does not cross the line in `domain.md`. Additive
field, no signature changed.

**`formatRelative` and `TIMEFRAME_SHORT` added to `format.ts`.** The cards need "2h
ago" and "ASAP"; `JOB_STATUS_LABELS` was also shortened to match the design's status
tags ("Open" rather than "Open for quotes").

**Fixtures extended, not rewritten.** The handoff's seed content is Austin-based with
six browse cards; the fixtures are San Francisco and are load-bearing for
`scripts/verify-rules.ts` (job ids, zips, cities, counts). Rewriting them would have
broken roughly fifteen assertions to make a demo look fuller. Instead the existing
photos became real self-hosted files and three open jobs (`job-6`–`job-8`) were added,
all owned by `user2` and inside an existing contractor's service area, so no assertion
moved. All 46 still pass.

**Four timeframes, not three.** The design's segmented control shows ASAP / This week /
Flexible. The domain has four, including `within_month`. A form that cannot express a
valid domain value is a bug, so all four render with the same treatment.

**Street and city fields added to the post-a-job form.** The design shows only ZIP, but
`JobInput` requires `street` and `city`, and the whole privacy model depends on an
exact address existing. The form collects them with a note that they stay private —
which is what the design's own rail copy promises.

**No star ratings on quote rows.** The design puts "4.9 ★ · 82 jobs" under the price.
There is no rating anywhere in the domain, so the slot carries the quote's age rather
than a fabricated number. `QuoteRow` has a comment marking where reviews go.

**"Your quotes" became its own route.** `listMatchedJobsForContractor` returns jobs the
contractor has *bid on*, not ones they won. Rendering that under a "Matched to you"
heading on the browse screen was both mislabelled and duplicated cards already in the
grid above. It moved to `/quotes`, which is what the folder sketch intended.

**Marketing counts stayed static.** The landing page's "128 open jobs" per trade needs
an un-authenticated aggregate the data layer does not have, and adding one would widen
its surface for a marketing figure. Left as copy, flagged in CLAUDE.md.

## Assets

Fourteen CDN images were downloaded and self-hosted per the handoff. They arrived at
87 MB (2048² PNGs); illustrations were resized to 640px and kept as PNG — the white
ground is what the `multiply` treatment cancels — and photography was converted to
JPEG at display width. Now 4 MB.

The bundled logo SVGs carry ~8 KB of C2PA metadata each and use viewBox `12 9 216 216`,
not the `48 22 144 190` tight crop the spec calls for. Clean files were written to
`public/brand/`, and `components/ui/Logo.tsx` inlines the same two paths so the
two-tone ink variant needs no extra request.

## Verification

- `npm run verify` — 46/46
- `npx tsc --noEmit`, `npm run lint` — clean
- `npm run build` — all routes prerender
- Every screen screenshotted headlessly at 1440, 768 and 390px: no console errors and
  no horizontal overflow at any width. The frozen-after-acceptance state and the
  winning contractor's unlocked address were both confirmed on screen.
